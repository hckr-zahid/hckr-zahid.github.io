Research & Analysis

RESEARCH #01 • STATIC ANALYSIS
Published 2024
Target: irm | iex & MAS_AIO.cmd
Scope: Windows OS Integrity

Static Security Analysis of a PowerShell-Based Windows Activation Workflow

A static source-code security review of a PowerShell-based Windows activation workflow initiated by irm https://get.activated.win | iex, including analysis of the launcher behavior and the associated MAS_AIO.cmd script. The research examines licensing-related system modifications, DLL replacement mechanisms, scheduled tasks, registry and service changes, and network behavior.

Scope & Methodology: This project is based strictly on static source-code analysis. The analyzed script was not executed as part of this research. Findings describe observed code behavior and potential risks; they do not establish that the script is malicious or guarantee that it is benign.

Five Primary Investigation Dimensions:

DIMENSION 01
Licensing Hooks & Activation
Examines HWID ticket generation, Ohook system hooks, KMS38 activation methods, and Online KMS server interactions.
DIMENSION 02
DLL Replacement Mechanics
Analyzes targeted replacement and interception of Windows licensing libraries (such as sppc.dll) and file integrity checks.
DIMENSION 03
Scheduled Tasks & Persistence
Investigates Task Scheduler persistence routines, renewal scripts, and automated execution hooks left across the operating system.
DIMENSION 04
Registry & Service Alterations
Documents changes made to Windows licensing registry hives, Software Protection Platform service states, and permission sets.
DIMENSION 05
Remote Download Vector
Evaluates security implications of the pipe-to-shell download pattern (irm ... | iex) without authenticated cryptographic validation.

Engineering Implementation Breakdown

PHASE 01 VMware Infrastructure

Isolated Subnet & Virtual Switching

Configured custom host-only virtual switch (VMnet10 / MyLabNet) scoped to 10.1.1.0/24, isolating the testbed from physical networks while enabling hypervisor inter-VM routing.

PHASE 02 Windows Server 2019

Static IP & Network Diagnostics

Provisioned DC01, resolved ARP address collision on 10.1.1.1, and statically bound 10.1.1.10/24 with self-referential DNS and 127.0.0.1 loopback resolver.

PHASE 03 Directory Services

AD DS Forest Root Promotion

Promoted DC01 to forest root domain controller for zroots.local with 2016 functional level, Global Catalog, authoritative DNS, and DSRM recovery protection.

PHASE 04 IAM & Governance

Organizational Units & Tiered RBAC

Structured OU taxonomy separating identities, servers, and computers. Engineered role-based security groups (IT-HelpDesk, Staff, Students, Management) enforcing least privilege.

PHASE 05 File Server & Storage

NTFS Hardening & Inheritance Severing

Structured corporate shares (CompanyData), severed inherited ACEs, established explicit permissions, and locked down departmental folders with granular Modify/Read ACLs.

PHASE 06 Client Integration

Domain Join & Kerberos Validation

Joined Windows 10 workstation (WIN10-01) to zroots.local, verified DC locator discovery via nltest /dsgetdc, and audited effective Kerberos token security attributes.
