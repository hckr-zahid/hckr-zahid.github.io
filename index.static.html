Modular Architecture & Engines

Architected a multi-threaded detection pipeline orchestrated through a central DynamicEngine. Modular sensors continuously analyze host metrics: Behavioral Engine for process execution trees, System Activity Engine for disk I/O and process CPU spikes, USB Monitor for peripheral insertion events, and Sandbox Engine for dynamic execution simulation.

Machine Learning & Detection Layer

Integrated trained supervised learning models on EMBER and CIC benchmark datasets, classifying malicious PDF and PE structural anomalies using LightGBM (pdf_model.lgbm). Combined with an indexed SQLite repository of 3,160,113 threat hashes, custom YARA heuristics, and regex pattern matching.

PyQt5 Real-Time Interface & SignalBus

Designed an asynchronous, dark-themed SOC interface with tabbed views for Dashboard, System Status, Threat Logs, Behavior Feed, Network Feed, and Quarantine Zone. Implemented a custom SignalBus pattern ensuring non-blocking background scanning while maintaining responsive UI updates and desktop notifications.

Automated Incident Remediation & Quarantine

Upon threat detection, CyberGun immediately isolates offending binaries into an encrypted Quarantine Zone with original path metadata, timestamping, and secure hash signatures. Provides SOC operators with safe file inspection, selective restoration, and permanent cryptographic destruction.

RESEARCH #01 • STATIC ANALYSIS PUBLISHED 2024

Static Security Analysis of a PowerShell-Based Windows Activation Workflow

A static source-code security review of a PowerShell-based Windows activation workflow initiated by irm https://get.activated.win | iex, including analysis of the launcher behavior and the associated MAS_AIO.cmd script. The research examines licensing-related system modifications, DLL replacement mechanisms, scheduled tasks, registry and service changes, and network behavior.

Scope & Methodology: This project is based on static source-code analysis. The analyzed script was not executed as part of the research. Findings describe observed code behavior and potential risks; they do not establish that the script is malware or guarantee that it is safe.
